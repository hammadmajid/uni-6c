1. A school database stores roll numbers. Insert the roll numbers [10, 5, 20, 3, 7, 30] into a BST and display them in inorder traversal.
2. A librarian organizes books using BST. Insert [50, 30, 70, 20, 40, 60, 80] and print preorder and postorder traversals.
3. A city's road network is modeled as a graph where intersections are nodes and roads are edges. A tourist wants to explore the city starting from a given intersection, visiting all intersections level by level (nearest first, then further ones). Implement BFS to simulate the traversal order of intersections.
4. A company has a clear hierarchy with a CEO at the top, managers below, and team leads under the managers. The HR system needs a way to display all employees level by level, starting from the CEO and moving downward through the organization. Write a program that performs this traversal using Breadth-First Search (BFS).
5. On a social media platform, when a user creates a post, it first reaches their direct friends. Those friends then share it further with their own friends. The platform should simulate how information spreads through the network using Breadth-First Search (BFS), showing the order in which users receive the post.
