<Predict
  id="ct1-q4"
  prompt="Q4. Write a function that calculates the average marks from a dictionary of students."
  answer="sum(marks.values()) / len(marks), with a guard for an empty dict."
>

```python
def average_marks(marks):
    if not marks:
        return 0.0
    return sum(marks.values()) / len(marks)

marks = {"Ali": 72, "Sara": 45, "Omar": 38}
print(average_marks(marks))   # 51.666666666666664
print(average_marks({}))      # 0.0
```

**Hidden edge cases:** an empty dict raises `ZeroDivisionError` without the guard. And the result is a float with a long tail, so format it with the `.2f` spec if it is going to be read by a person.

</Predict>

<Predict
  id="ct1-q5"
  prompt="Q5. A university stores student data (name, department, GPA) in a dictionary. Write a function to find the student with the highest GPA."
  answer="Key the dict by name, then max over the keys with a key function that reads the GPA."
>

```python
students = {
    "Ali":  {"department": "CS", "gpa": 3.1},
    "Sara": {"department": "AI", "gpa": 3.8},
    "Omar": {"department": "SE", "gpa": 3.8},
}

def top_student(students):
    return max(students, key=lambda n: students[n]["gpa"])

print(top_student(students))   # Sara
```

**Hidden edge case: ties.** Sara and Omar both have 3.8, and `max` returns the first one it meets in insertion order. If the question means "all students with the highest GPA", compute the best value first:

```python
def top_students(students):
    best = max(s["gpa"] for s in students.values())
    return [n for n, s in students.items() if s["gpa"] == best]

print(top_students(students))  # ['Sara', 'Omar']
```

</Predict>

<Predict
  id="lt1-q4"
  prompt="Q4. Employee data (name, department, salary) is in a dictionary. Increase the salary of every employee in the AI department by 15%."
  answer="Loop over the employee records, test the department, multiply by 1.15, and round."
>

```python
employees = {
    "E1": {"name": "Ali",  "department": "AI", "salary": 150000},
    "E2": {"name": "Sara", "department": "HR", "salary": 120000},
    "E3": {"name": "Omar", "department": "AI", "salary": 99999},
}
for emp in employees.values():
    if emp["department"] == "AI":
        emp["salary"] = round(emp["salary"] * 1.15, 2)
print(employees["E3"]["salary"])   # 114998.85
```

**Hidden edge cases.** First, floats: `99999 * 1.15` is `114998.84999999999`, and `50000 * 1.15` is `57499.99999999999`, because 1.15 has no exact binary representation. Round money for display, or keep it in integer paisa and compute `salary * 115 // 100`. Second, the type changes: 150000 was an int and comes back as `172500.0`. Third, the dict is mutated in place: `emp` is the inner record itself, not a copy, which is why assigning to `emp["salary"]` works.

</Predict>

<Predict
  id="lt1-q5"
  prompt="Q5. A shopping cart is a dict from item to price. Write a function that returns the total bill after a 5% discount if the total exceeds 1000."
  answer="Sum the values; if total > 1000 multiply by 0.95; return the rounded total."
>

```python
def bill(cart):
    total = sum(cart.values())
    if total > 1000:
        total *= 0.95
    return round(total, 2)

print(bill({"pen": 200, "notebook": 800}))   # 1000
print(bill({"pen": 200, "notebook": 801}))   # 950.95
print(bill({}))                              # 0
```

**Hidden edge case:** "exceeds 1000" means strictly greater, so a total of exactly 1000 gets no discount. Writing `>=` is the most common mistake on this question. Say which reading you chose in a comment if the wording is ambiguous in an exam. Also note the discount threshold applies to the total, not per item.

</Predict>
