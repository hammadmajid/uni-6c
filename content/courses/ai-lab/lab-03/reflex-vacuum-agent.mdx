AI lecture 2 defined an agent as something that perceives its environment through sensors and acts on it through actuators, and drew the two-square vacuum world. Today you write both halves in Python: the world as a class, and the agent as a function from percept to action. There is no lab manual yet, so this follows the Russell and Norvig code the lecture's slides come from. The theory side is in the [AI course, week 2](/learn/ai/week-02/agents-and-rationality).

**It shuttles forever:** Right, Left, Right, Left, Right, Left. The rules only look at the current percept, which is always "clean", and the only clean-square rules say move. There is no percept that means "the whole world is clean", because the agent can only ever see one square.

Whether that matters depends on how you score it. If the performance measure only rewards clean squares, shuttling costs nothing. If each move costs a point, as it would with a real battery, this agent is irrational. That is the whole point of the second lesson.

</Predict>

## The world is a class, the agent is a function

<Callout type="key-idea" title="Map the lecture's words onto the code">
**Sensors** → `percept()`, which returns what the agent can see. **Actuators** → `execute(action)`, which changes the world. **Agent function** → the Python function from percept to action. **Performance measure** → the score that `run` computes. The agent never touches `world.status` directly; it only ever gets a percept.
</Callout>

```python
class VacuumWorld:
    def __init__(self, status, location="A"):
        self.status = dict(status)      # e.g. {"A": "Dirty", "B": "Clean"}
        self.location = location

    def percept(self):                  # the sensors
        return (self.location, self.status[self.location])

    def execute(self, action):          # the actuators
        if action == "Suck":
            self.status[self.location] = "Clean"
        elif action == "Right":
            self.location = "B"
        elif action == "Left":
            self.location = "A"
        # "NoOp" changes nothing

    def clean_squares(self):
        return sum(1 for s in self.status.values() if s == "Clean")
```

`dict(status)` copies the dict that was passed in, so running the world does not mutate the caller's dict. That is the aliasing rule from lab 02 again.

## The agent: condition-action rules

The simple reflex agent maps the **current** percept straight to an action with if-then rules. The lecture calls them condition-action rules. It has no memory at all.

```python
def reflex_vacuum_agent(percept):
    location, status = percept
    if status == "Dirty":
        return "Suck"
    elif location == "A":
        return "Right"
    elif location == "B":
        return "Left"
```

## The loop that runs it

```python
def run(world, agent, steps=6, move_cost=0):
    score = 0
    for t in range(1, steps + 1):
        percept = world.percept()
        action = agent(percept)
        world.execute(action)
        score += world.clean_squares()
        if action in ("Left", "Right"):
            score -= move_cost
        print(t, percept, action, score)
    return score

world = VacuumWorld({"A": "Dirty", "B": "Dirty"}, location="A")
run(world, reflex_vacuum_agent)
```

```text
1 ('A', 'Dirty') Suck 1
2 ('A', 'Clean') Right 2
3 ('B', 'Dirty') Suck 4
4 ('B', 'Clean') Left 6
5 ('A', 'Clean') Right 8
6 ('B', 'Clean') Left 10
```

<Deeper kind="edge" title="When is the reflex agent actually rational?">

Russell and Norvig's answer: it is rational **if** the performance measure does not penalise movement, the geography is known (two squares), and the only actions are Left, Right and Suck. Change any one and it stops being rational. Add a move cost and it wastes points; let dirt reappear and shuttling becomes useful again. Rationality is always relative to the performance measure, which is why PEAS starts with P.

</Deeper>
