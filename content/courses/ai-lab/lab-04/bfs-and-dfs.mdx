Lab 03 ended with the point that a real goal-based agent has to find a sequence of actions that reaches its goal. Search is how it finds one. Both algorithms in this lesson run the same loop: take a node off the frontier, expand it, and put its neighbours on the frontier. The only difference is whether the frontier is a queue or a stack, and that one choice decides which path comes back.

## The frontier decides everything

| | BFS | DFS |
|---|---|---|
| Frontier | queue, FIFO: `deque.popleft()` | stack, LIFO: `list.pop()` |
| Expands | shallowest node first, layer by layer | deepest node first, one branch at a time |
| Path returned | fewest edges | whichever branch reaches the goal first |
| Complete (finds a path if one exists)? | yes, on a finite graph | yes on a finite graph, if it tracks explored nodes |
| Optimal? | yes, when every step costs the same | no |
| Memory | O(b^d): a whole layer is on the frontier | O(b·m): one branch plus its siblings |

Here b is the branching factor, d the depth of the shallowest goal, and m the maximum depth. The memory row is why DFS still matters: in a wide tree, BFS's frontier grows exponentially before it finds anything.

## BFS in Python

```python
from collections import deque

graph = {
    "A": ["B", "C"],
    "B": ["A", "D", "E"],
    "C": ["A", "F", "G"],
    "D": ["B", "H"],
    "E": ["B", "H"],
    "F": ["C"],
    "G": ["C", "H"],
    "H": ["D", "E", "G"],
}

def path_to(parent, node):
    path = []
    while node is not None:
        path.append(node)
        node = parent[node]
    return path[::-1]

def bfs(graph, start, goal):
    frontier = deque([start])         # FIFO queue
    parent = {start: None}            # also the "reached" set
    order = []
    while frontier:
        node = frontier.popleft()
        order.append(node)
        if node == goal:
            return path_to(parent, goal), order
        for nbr in sorted(graph[node]):
            if nbr not in parent:
                parent[nbr] = node
                frontier.append(nbr)
    return None, order

print(bfs(graph, "A", "G"))
# (['A', 'C', 'G'], ['A', 'B', 'C', 'D', 'E', 'F', 'G'])
```

The `parent` dict does two jobs. It records how each node was first reached, so `path_to` can walk back from the goal. It is also the set of nodes already reached, so a node is never enqueued twice. Drop that check and an undirected graph loops forever: A enqueues B, B enqueues A, and so on.

## DFS in Python

```python
def dfs(graph, start, goal):
    frontier = [start]                # a list used as a stack
    parent = {start: None}
    explored = set()
    order = []
    while frontier:
        node = frontier.pop()         # LIFO
        if node in explored:
            continue
        explored.add(node)
        order.append(node)
        if node == goal:
            return path_to(parent, goal), order
        for nbr in sorted(graph[node], reverse=True):
            if nbr not in explored:
                parent[nbr] = node
                frontier.append(nbr)
    return None, order

print(dfs(graph, "A", "G"))
# (['A', 'B', 'D', 'H', 'G'], ['A', 'B', 'D', 'H', 'E', 'G'])
```

Two details differ from BFS, and both exist to make the trace match what you would draw by hand. Neighbours are pushed in **reverse** alphabetical order so the alphabetically first one ends up on top and is expanded first. And a node can be on the stack twice (pushed once by each neighbour), so a popped node that is already explored is skipped. This version expands nodes in exactly the order a recursive DFS visits them.

<Deeper kind="beyond" title="Iterative deepening: DFS memory with BFS answers">

Run DFS with a depth limit of 0, then 1, then 2, and so on until the goal turns up. Each round repeats the shallow work, but in a tree with branching factor b the last layer dominates, so the total costs only about b/(b − 1) times one full search. You get BFS's shortest path and completeness with DFS's O(b·d) memory. Russell and Norvig call it the preferred uninformed method when the search space is large and the goal depth is unknown.

</Deeper>
