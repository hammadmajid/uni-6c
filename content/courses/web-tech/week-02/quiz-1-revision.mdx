## Short answers

<Predict
  id="q1-write-person"
  prompt="Write a class Person with a private name field, a constructor that sets it, and getName(); a class Student that extends Person and passes the name up; and a main that creates a Student named Ali and prints his name. All in package com.example. (5 marks)"
  answer="Person: private String name; public Person(String name) with this.name = name; public String getName() returning name. Student extends Person with a constructor Student(String name) that calls super(name). Main's main does Student s = new Student(&quot;Ali&quot;); System.out.println(s.getName());, which prints Ali."
>

```java
// com/example/Person.java
package com.example;

public class Person {
    private String name;

    public Person(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}

// com/example/Student.java
package com.example;

public class Student extends Person {
    public Student(String name) {
        super(name);
    }
}

// com/example/Main.java
package com.example;

public class Main {
    public static void main(String[] args) {
        Student s = new Student("Ali");
        System.out.println(s.getName());   // Ali
    }
}
```

The marks: `private` field with a constructor using `this.name = name` (1), `getName` (1), `extends Person` (1), `super(name)` in Student's constructor (1), and a main that creates and prints (1). The most common lost mark: leaving out `super(name)`. Then the compiler inserts `super()`, and Person has no no-argument constructor, so it does not compile.

</Predict>

<Predict
  id="q1-employee-array"
  prompt="Slide 49's exercise: Employee is abstract with name, getName() and abstract double earnings(). SalariedEmployee and HourlyEmployee extend it. Create an array of Employee, store one of each, and print every employee's name and earnings. Write the main method only. (4 marks)"

```java
    Employee[] staff = new Employee[2];
    staff[0] = new SalariedEmployee("Zubair", 50000);
    staff[1] = new HourlyEmployee("Ali", 1500, 20);

    for (int i = 0; i < staff.length; i++) {
        System.out.println(staff[i].getName() + ": " + staff[i].earnings());

}
// Zubair: 50000.0
// Ali: 30000.0
```

The marks: an array declared with the abstract type (1), concrete objects stored in it (1), the loop (1), and calling `earnings()` through the Employee reference (1), where each object runs its own version. For the List version (slide 50), write `List<Employee> list = new ArrayList<>();`, then `list.add(...)`, then `for (Employee e : list)`. That needs `import java.util.List;` and `import java.util.ArrayList;`, since only `java.lang` is imported automatically.

<Predict
  id="q1-explain-run"
  prompt="Explain what happens from typing javac Main.java to seeing Hi printed, using the terms from the slides. (4 marks)"
  answer="javac compiles Main.java into Main.class, containing bytecode. java Main starts a process that boots the JVM. The JVM initialises its subsystems (GC, JIT, class loader), loads the bootstrap classes (Object, String) and then Main through the class loader into the method area, creates the main thread with its own stack, and calls main, which runs System.out.println. When main finishes the JVM exits with code 0."
>

1. **Compilation:** `javac Main.java` compiles the source into `Main.class`, which contains **bytecode**, not machine code.
2. **Launch:** `java Main` starts a process that boots the **JVM**. The JVM initialises its subsystems: the garbage collector, the JIT compiler and the **class loader**.
3. **Loading:** the class loader loads the bootstrap classes (`java.lang.Object`, `java.lang.String`), then `Main`, into the **method area**.
4. **Execution:** the JVM creates the **main thread**, which gets its own Java stack, and calls `main`. The execution engine runs the bytecode, and `println` writes `Hi` through a native method.
5. **Exit:** when `main` returns, the JVM shuts down with exit code **0**; an uncaught exception would give a non-zero code.

For a class in a package, the commands are `javac com/example/Main.java` and `java com.example.Main`, run from the project root. The slides' bare `java Main` works only for a class with no package statement.

</Predict>
