<Predict
  id="cp-long-function-program"
  prompt="Differentiate between the agent function and the agent program, using the vacuum-cleaner world as an example. (3 marks)"
  answer="The agent function is an abstract mathematical mapping from every possible percept sequence to an action, F: P* → A; for the vacuum world it is a table such as [A, Clean] → Right, [A, Dirty] → Suck, [A, Clean], [A, Clean] → Right, which grows without bound. The agent program is concrete code that implements the function on the architecture, for example REFLEX-VACUUM-AGENT: if status = Dirty then Suck, else if location = A then Right, else Left. Four lines of program implement an infinite table."
>

**Agent function**: abstract, a mapping from percept sequences to actions (F : P* → A). It can be written as a table, usually an infinite one. Vacuum example: [A, Dirty] → Suck; [A, Clean] → Right; [A, Clean], [A, Clean] → Right; and so on, one row per history.

**Agent program**: concrete code running on the architecture that implements the function with finite memory. Vacuum example: REFLEX-VACUUM-AGENT, which checks whether the square is dirty and otherwise moves to the other square.

**The point**: a four-line program implements an unbounded table, and designing such programs is the job of AI.

</Predict>
