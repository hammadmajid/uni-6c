## Long answers

Write these out, on paper or in a text editor, then reveal and compare. The model answers are what a full-marks response contains, not the only wording.

<Predict
  id="cp-need-for-layers"
  prompt="Explain the need for a layered architecture in communication networks. (5 marks)"
  answer="Complexity management via modularity; each layer offers a service model to the one above; implementations can change independently; interoperability of vendors; application count plus link count instead of their product. Mention one drawback for balance."
  placeholder="Write the answer you would give in the exam."
>

A full-marks answer contains:

1. **The problem**: networks are complex systems with many hardware and software pieces from many vendors; without structure, every piece would depend on every other.
2. **The mechanism**: divide the functionality into layers, each providing a service to the layer above using the services of the layer below (the service model).
3. **Benefit 1, modularity**: each layer can be designed, discussed and tested on its own.
4. **Benefit 2, independence**: the implementation of a layer can change without affecting the others, as long as the service is unchanged. New link technologies appear without applications changing.
5. **Benefit 3, interoperability and scale**: with A applications and L link types, layering needs A + L implementations instead of A × L.
6. **Balance**: one sentence on drawbacks, such as duplicated functionality across layers or the occasional need for a layer to use information from another.

</Predict>
